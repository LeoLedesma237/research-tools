Fitting a Hierarchical DDM on GNG data

The goal of this document is to walkthrough the creation of hierarchicall GNG data followed by the model fitting process.

# load in packages
library(EMC2)
library(dplyr)
library(here)
library(ggplot2)
# Load custom DDM functions
source(here("ddm", "load.R"))

1. Generating the GNG data

1.1 Specifying the model and data making information

We start by specifying that we want to have a dataset comprised of 60 subjects. This will be a Go/No-Go (GNG) datasets where most trials will require a response (go) while the fewer remaining trials will not (nogo). To create the backbone of what we want, we start by using the design() function, which specifies both the design of the data and the model (DDM) that we will use.

We start by specifying our main factors of interest which are subjects, and S (stimuli). We state that we want data for 60 participants and that the data will be made up of “go” and “nogo” stimuli. Next, we indicate what the responses are going to be, which are “go” and “nogo”. As is, these responses do not mean anything to the model. However, we can then supply more information into ‘matchfun’ and ‘functions’ arguments, which tell the model a) which boundary the “go” and “nogo” response will represent, with the “go” response representing the bottome or negative boundary (idk).

From there, we specify what model we want to use which is the DDM, followed by the formula. The formula we chose is a regular Wiender diffusion model (WDM). Lastly, since we specify within trial-error into the formula (s), we also add this paramter into ‘constants’, such that the model knows to fix this value rather than estimate it.

# Number of subjects
sub_n <- 60

# Create model design
designWDM <- design(
  factors = list(subjects = 1:sub_n, S = c("go", "nogo")),
  Rlevels = c("go", "nogo"),
  matchfun = function(d) as.numeric(d$S) == as.numeric(d$lR),
  functions = list(match = function(d) ifelse(d$S == "go", -1, 1)),
  model = DDM,
  formula = list(
    v ~ 0 + match:S,
    Z ~ 1,
    a ~ 1,
    t0 ~ 1,
    s ~ 1
  ),
  constants = c(s = log(1))
)

1.2 Specifying the population level parameters

Here we are creating two vectors that contain information about the population level parameters. These are going to be the value that will represent the average estimates across all subjects in the sample. In other words, we can think of the drift rates below as like the mean of all the drift rates from all subjects within the sample (with some caveats). Additionally, we are not solely specifying the values we want for the drift rates and other parameters, but also their distributions. Lastly, it is important to note when specifying the values below, to use the correct transformations, as the transformed value is what will be used during the model estimation process.

# Population means
p_vector <- sampled_pars(designWDM)

p_vector["v_match:Sgo"] = .9
p_vector["v_match:Snogo"] = 1.25
p_vector["a"] = log(1.2)
p_vector["t0"] = log(.4)
p_vector["Z"] = qnorm(.4)

# Between-subject standard deviations
p_sd <- sampled_pars(designWDM)

p_sd["v_match:Sgo"] = .15
p_sd["v_match:Snogo"] = .15
p_sd["a"] = .05
p_sd["t0"] = .05
p_sd["Z"] = .10

1.3 Specifying the subject level parameters

For this section, we are interested in creating DDM parameters for each person in the data. We start by creating an empty matrix to store this information in, then using a for loop, for each row (subject) we randomly pick a number from the parameter distributions created in the previous section. We do this using the rnorm() function, were we provide a mean and standard deviation for a normal distribution and the function returns a value from it. In our case, this function returns back 5 values, which in order are the go and no-go drift rates, followed by Z, a and t0.

We set a seed number to replicate our results from rnorm().

# Generate subject-specific parameters
set.seed(123)

# Create an empty matrix to keep subject specific parameters
p_subjects <- matrix(NA, nrow = sub_n, ncol = length(p_vector))

# For every subject, pick a parameter value at random from the population level distributions
for (i in 1:sub_n) {
  p_subjects[i, ] <- rnorm(length(p_vector), mean = p_vector,sd = p_sd)
}

# Assign row and column names
rownames(p_subjects) <- as.character(1:sub_n)
colnames(p_subjects) <- names(p_vector)

1.3 Creating the data

The data creation part has two components since we want an unequal number of go and no-go trial. Most GNG datasets in the literature have a disproportionate number of go trials to habituate making a responses. Thus, here we need to create an empty dataframe that has the data specifications we have, which include the number of trials equal to the number of subjects in our data and the number of go and no-go trials each subject has (adds up to 1000). Plus, we also need to specify that our responses “go” and “nogo” are a factor or else the following function wont work.

Lastly, we use the make_data() function and it creates our data. Notice the inputs for this data are the subject-level parameters, the data and model object, and our empty data structure.

# Construct an unbalanced trial dataset
trial_design <- expand.grid(
  subjects = 1:sub_n,
  trial = 1:1000) %>%
  group_by(subjects) %>%
  mutate(
    S = rep(c("go", "nogo"), times = c(800, 200)),
    S = factor(S, levels = c("go", "nogo")),
    R = factor(NA_character_, levels = c("go", "nogo"))) %>% # Must be a factor even though empty
  ungroup()

# Generate simulated responses and RTs
dat <- make_data(
  parameters = p_subjects,
  design = designWDM,
  data = trial_design
)

3. Specifying our Priors

3.1 Specifying the prior means

# Get an empty vector with DDM parameter names
prior_pvec <- sampled_pars(designWDM)

# Specify population-level prior means
prior_pvec[grepl("^v_", names(prior_pvec))] <- 2
prior_pvec["a"] <- log(1)
prior_pvec["Z"] <- qnorm(.5)
prior_pvec["t0"] <- log(.4)

3.2 Specifying the prior variances

# Specify population-level prior variances
prior_vvec <- sampled_pars(designWDM) + 1

prior_vvec["Z"] <- .5
prior_vvec["t0"] <- .5
prior_vvec["a"] <- .25
prior_vvec["t0"] <- .10

3.3 Creating the prior distributions

# Print this out to know how to correctly specify the inputs of prior
prior_help("standard")
type: mu 
Group-level mean 

  Hyperparameters: 
  - theta_mu_mean : mean of the group-level mean prior 
  - theta_mu_var : variance of the group-level mean prior 

type: Sigma 
Group-level covariance matrix 

  Hyperparameters: 
  - v : degrees of freedom on the group-level (co-)variance prior, 2 leads to uniform correlations. Single value 
  - A : scale on the group-level variance prior, larger values lead to larger variances 
# Create hierarchical prior
prior <- prior(
  design = designWDM,
  type = "standard",
  theta_mu_mean = prior_pvec,
  theta_mu_var = prior_vvec
)

3.4 Plotting the prior distributions

# Inspect priors
plot(prior, map = FALSE)
plot(prior, map = TRUE)
