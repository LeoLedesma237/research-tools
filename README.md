# Research Tools

A collection of guides, code, and custom functions for statistical modeling and research methods in R.

## Contents

### Drift Diffusion Models

Guides and code for fitting and evaluating drift diffusion models.

- DDM overview
- Model fitting
- Model evaluation
- Parameter recovery
- Go/No-Go DDMs

### Item Response Theory

Guides and code for item response theory models.

### Mixed-Effects Models

Guides and code for fitting and evaluating mixed-effects models.

The rendered guides are available through the Research Tools GitHub Pages website.

## Purpose

This repository serves as a personal reference for statistical methods and R code that I use in research. The guides focus on both the conceptual foundations of each method and their practical implementation.
